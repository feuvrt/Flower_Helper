# Flower Helper / PlantCare 🌿

Flower Helper — веб-приложение для подбора комнатных растений и ухода за собственной коллекцией.

Приложение помогает выбрать растение под конкретные условия, узнать информацию об уходе, определить растение по фотографии, сохранить понравившиеся варианты и следить за поливом и пересадкой домашних растений.

Проект разработан самостоятельно.

## Возможности

### 🌱 Каталог растений

В приложении есть справочник комнатных растений с информацией о:

* условиях освещения;
* частоте полива;
* пересадке;
* сложности ухода;
* размере растения;
* безопасности для домашних животных;
* других особенностях растения.

В каталоге реализованы поиск и фильтрация.

### ✨ Подбор растения

Flower Helper может подобрать подходящие растения по ответам пользователя.

При подборе учитываются:

* опыт ухода за растениями;
* количество света в помещении;
* наличие детей или домашних животных;
* желаемая частота полива;
* приоритеты пользователя;
* температура в помещении;
* растения, которые уже есть в коллекции.

Для каждого растения рассчитывается степень соответствия выбранным условиям и отображаются причины, почему оно подходит или не подходит пользователю.

### 📷 Определение растения по фотографии

Пользователь может загрузить фотографию растения и попробовать определить его вид.

Для распознавания используется **Pl@ntNet API**.

Приложение получает несколько возможных результатов, показывает вероятность совпадения и пытается сопоставить найденное растение с локальным каталогом Flower Helper.

### 💚 Моя коллекция

Пользователь может вести собственную коллекцию домашних растений.

Растение можно:

* добавить из общего каталога;
* создать вручную, если его нет в справочнике;
* дополнить заметками;
* указать дату последнего полива;
* указать дату пересадки;
* настроить интервалы ухода;
* редактировать;
* удалить из коллекции.

Также поддерживается импорт и экспорт коллекции в JSON.

### 🔔 Напоминания об уходе

Для растений рассчитываются задачи по уходу.

Можно отслеживать:

* необходимость полива;
* необходимость пересадки.

Приложение поддерживает браузерные уведомления и позволяет отмечать выполненный полив или пересадку.

### ⭐ Избранное

Понравившиеся растения можно сохранять в отдельный список избранного.

Для авторизованного пользователя избранное синхронизируется с аккаунтом.

### 👤 Авторизация и синхронизация

В приложении реализованы регистрация и вход через **Supabase Auth**.

После авторизации с аккаунтом синхронизируются:

* коллекция растений;
* избранное;
* пользовательские настройки.

Без регистрации приложение можно использовать в гостевом режиме — пользовательские данные сохраняются локально на устройстве.

Если пользователь сначала работал без аккаунта, локальные данные можно перенести в Supabase после авторизации.

### 🌙 Тема

Поддерживаются светлая и тёмная темы.

Для авторизованного пользователя настройка темы также сохраняется в аккаунте.

## Структура проекта

Основной код находится в `src`.

### `pages`

Страницы приложения:

* `HomePage` — главная страница;
* `CatalogPage` — каталог растений;
* `PlantPage` — подробная информация о растении;
* `RecommendationsPage` — подбор растений;
* `IdentifyPage` — определение растения по фотографии;
* `CollectionPage` — коллекция пользователя;
* `FavoritesPage` — избранное;
* `AuthPage` — регистрация и авторизация.

### `components`

Переиспользуемые компоненты интерфейса: карточки растений, формы, модальные окна, уведомления, элементы коллекции и другие компоненты.

### `services`

Работа с внешними сервисами и данными:

* `plantNetApi.ts` — запросы к Pl@ntNet API;
* `recommendationService.ts` — логика подбора растений;
* `supabaseClient.ts` — подключение к Supabase;
* `supabaseData.ts` — работа с данными в Supabase.

### `utils`

Вспомогательная логика приложения: работа с датами, локальным хранилищем, растениями и напоминаниями.

## Запуск проекта

Для запуска потребуется Node.js и npm.

1. Клонировать репозиторий.

2. Установить зависимости:

```bash
npm install
```

3. Создать файл `.env` и указать необходимые переменные:

```env
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
VITE_PLANTNET_API_KEY=your_plantnet_api_key
```

4. Запустить приложение:

```bash
npm run dev
```

5. Для production-сборки:

```bash
npm run build
```
